# Catacomb encounter contract

All Act 0 catacomb encounters are deterministic authored tutorial encounters.

- Room 1: baseline skeleton, reinforces target + A1/A2.
- Room 2: hound, reinforces pressure/cooldown timing.
- Room 3: defensive enemy, reinforces visible Guard state.
- Room 4: stronger 1v1 readiness check.
- Room 5 first visit: two enemies. Solo Shadow is forced into the authored solo-limit outcome after the lesson is established; this is not presented as an ordinary random defeat.
- Room 5 rematch: same two-enemy identity, now with the story companion / second team slot.

The first Room 5 state must never be converted into a grind wall. No random stat roll or gear drop determines access to the story summon.
