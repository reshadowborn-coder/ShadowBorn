# CH00 Graybox v0.2

## Playable route contract
Three compact visual cells create the illusion of one larger location:
- CEM_01: Awakening / cemetery / Hound.
- RUIN_01: broken stairs / Armless Skeleton.
- TEMPLE_EXT_01: temple reveal / Shield Skeleton / gate.

## Camera composition
Camera is intentionally closer than a broad RAID arena for Chapter 0 1v1 readability. Player should occupy left/near third during combat staging; enemy silhouette and state must remain readable on the opposite side.

## Mobile cost rules
No dense transparent fog cards in graybox. No realtime environment shadow budget assumed. Three ground chunks, reusable primitive/proxy architecture, collision to be added only to playable blockers.

## Shield lesson correction
Shield Boss begins in a readable Brace/Guard state before the player's first command. Guard then exits after its authored opening turn. Exact balance remains provisional.
