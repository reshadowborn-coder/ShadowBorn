# ACT 0 — COMPLETE SCOPE CONTRACT

Act 0 does not end at the exterior temple gate. The temple is part of Act 0.

## Exterior
Identity/formation -> awakening -> grave corridor -> Hound -> residual absorption -> Armless Skeleton -> temple reveal -> Shield Skeleton -> first Silver -> sigil threshold -> temple entry.

## Temple interior
The temple is the first safe hub and onboarding space. It contains:
- Keeper / narrative handoff;
- Smith and scripted first forge;
- Merchant station;
- Engraver / rune-enchantment station placeholder;
- Forgotten Covenant;
- five Shadow weapon-family choices: Sword+Shield, Bow, 2H Axe, Dual Daggers, 2H Mage Staff;
- A1/A2 preview; P1 remains locked until Lv10;
- route toward catacombs.

## Catacombs tutorial tail
Rooms 1–4 are authored 1v1 encounters. Room 5 is an authored solo-limit 1v2 defeat. The player returns to the Temple, receives the first story summon/team slot, then can rematch.

## Act 0 completion condition
Act 0 is complete only after:
1. exterior route cleared;
2. Temple entered;
3. Forgotten Covenant joined;
4. one weapon family selected;
5. scripted first forge/equip committed atomically;
6. first story summon/team slot introduced through the Room 5 limit;
7. Room 5 rematch resolved;
8. save/resume works across every irreversible transition.

Final production art/audio/content polish remains separate from gameplay-complete status.
