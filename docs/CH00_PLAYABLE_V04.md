# Chapter 0 Playable v0.4

## Added
- Procedural graybox silhouettes for Skeleton Hound, Armless Skeleton, and Rusted Shield Skeleton.
- Shield boss visually has one surviving arm and a large old wooden shield.
- Combat staging repositions Shadow and enemy into a readable left-vs-right duel composition.
- Camera transitions to a closer combat framing and returns to exploration framing after combat.
- Shield visual reacts to authoritative Guard state; Guard is readable before the first command.
- Defeated enemy visual is removed from the route.

## Intent
This is still graybox. Primitive meshes exist to validate silhouette, framing, combat distance, Guard readability, and mobile camera composition before any production model is introduced.
