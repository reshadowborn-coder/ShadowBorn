# Act 0 Temple onboarding flow

The Temple is a safe onboarding hub, not a menu dump.

1. Entry: control returns inside the nave. No combat UI.
2. Keeper: short narrative handoff; unlocks Forgotten Covenant interaction.
3. Covenant: player sees five weapon silhouettes. Selection shows only combat feel, A1 identity and A2 identity. P1 is visibly LOCKED until Lv10.
4. Confirming a family is an explicit decision. School/Affiliation is not silently changed.
5. Smith: scripted first forge costs the first Silver earned from Shield Skeleton. Forge creates and equips the selected shadow weapon.
6. Only after the forge commits does the catacomb route open.
7. Merchant and Engraver are present spatially but do not dump their full systems during this onboarding.

## Atomic first-forge rule
Validation -> Silver debit -> item creation -> equip -> progression stage -> save must be committed as one authoritative state transition. A crash must recover to either the complete pre-forge state or complete post-forge state; never silver spent with no item.

## UI contract
Weapon choice never advertises a passive as immediately available. P1 is locked to character Lv10. Aura and Talents/Masteries are not introduced in Act 0.
