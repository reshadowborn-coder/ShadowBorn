# First story summon — Act 0 implementation contract

The first companion is a deterministic story unlock, not a random summon and not part of the summon economy.

Working implementation identity: Gravebound Warden. This is a production placeholder name until narrative naming is approved.

Purpose in Room 5 rematch:
- make the second team slot immediately understandable;
- absorb pressure from the second enemy;
- provide a simple protector loop without introducing aura, talents or extra meta systems;
- fixed visual equipment, consistent with non-Shadow heroes.

The first Room 5 1v2 is an authored solo-limit state. After it is seen, the Temple story handoff unlocks this companion and marks the rematch ready. No currency roll, rarity roll or generated-character pipeline is involved.
