# Chapter 0 Playable v0.3

Adds a real gameplay loop to the graybox: three Area3D encounter triggers, movement lock during combat, A1/A2 HUD, HP/state display, A2 cooldown display, Shield opening Guard readability, victory checkpoint progression, death reset and retry position.

This remains a prototype: placeholder meshes, no final animation/VFX/audio, no persistence to disk yet. Combat resolver remains the single authority for damage.
